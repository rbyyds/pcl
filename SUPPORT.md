# Support / 客服支持

## Getting Help

If you need help with the Point Cloud Library (PCL), the following support channels are available:

### Community Support (免费社区支持)

- **Discord**: Join our [Discord Server](https://discord.gg/JFFMAXS) for live chat with other members of the PCL community and casual discussions.
- **Stack Overflow**: Post questions tagged with [`point-cloud-library`](https://stackoverflow.com/questions/tagged/point-cloud-library) for Q&A, troubleshooting, installation, and debugging help.
- **GitHub Issues**: Use the [issue tracker](https://github.com/PointCloudLibrary/pcl/issues) for bug reports and feature requests. Please read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting.

### Documentation (文档)

- [Tutorials](https://pcl-tutorials.readthedocs.io/)
- [API Documentation](https://pointclouds.org/documentation/)

### Before Asking for Help (提问前请先)

1. Check the [documentation](https://pointclouds.org/documentation/) and [tutorials](https://pcl-tutorials.readthedocs.io/).
2. Search [Stack Overflow](https://stackoverflow.com/questions/tagged/point-cloud-library) for similar questions.
3. Search existing [GitHub Issues](https://github.com/PointCloudLibrary/pcl/issues).

### Reporting Bugs (报告错误)

Please read [CONTRIBUTING.md#bug-reports](CONTRIBUTING.md) for guidelines on how to submit a good bug report.

---

*Note: PCL is an open-source project maintained by volunteers. There is no dedicated paid customer service team. All support is provided by the community on a best-effort basis.*
